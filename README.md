# おぼえ帳

なんでも登録できるシンプルな単語帳ウェブアプリ。単一HTML・通信ゼロ・データは端末内（localStorage）のみ。

## しくみ

- 新しいカードは「おぼえる」コーナーで練習。「覚えた」を3回連続で復習コーナーへ
- 復習コーナーは忘却曲線に沿って 1日 → 3日 → 7日 → 14日 → 30日 の間隔で出題
- 30日後の復習をクリアで「習得ずみ」。復習で忘れていたら「おぼえる」へ戻る
- カード登録は 1枚ずつ／表の貼り付け／CSV読み込み／AI用プロンプト生成に対応
- 読み上げ機能つき（端末内蔵の音声合成。英語・日本語を自動判別）
- バックアップはCSV/JSONの書き出し・復元

## 使い方

`index.html` をブラウザで開くだけ。ビルド・サーバー不要。
